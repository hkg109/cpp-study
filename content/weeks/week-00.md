# 첫 C++ 프로그램: 값을 저장하고 계산하기

화면에 문장을 출력하는 프로그램에서 시작해, 상품 가격을 계산하는 프로그램까지 함께 만듭니다. 처음에는 모든 기호를 외우기보다 코드를 한 줄씩 바꾸고 결과를 확인하는 데 집중하세요.

## 수업 목표와 진행 순서

**준비:** C++ 코드를 빌드하고 실행할 수 있는 환경이 필요합니다. 편집기는 코드를 쓰는 도구이고, 컴파일러는 코드를 번역하는 도구입니다. VS Code 설치만으로 컴파일러가 준비되지는 않습니다.

수업이 끝나면 다음을 할 수 있습니다.

- 정수 나눗셈, 나머지, 대입과 비교의 결과를 예측합니다.

## 1. 먼저 한 번 실행해 보기

다음 전체 코드를 `main.cpp`에 저장하고 실행합니다. **이 페이지에서 `#include`와 `main`이 있는 코드는 각각 독립된 프로그램**입니다. 예제를 여러 개 실행할 때는 파일 내용을 교체하세요.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World" << '\n';
    return 0;
}
```

출력:

```text
Hello World
```

GCC가 설치된 터미널에서는 다음처럼 빌드합니다. 빌드는 실행 파일을 만드는 과정입니다.

```sh
g++ -std=c++17 -Wall -Wextra main.cpp -o hello
```

Windows PowerShell에서는 `./hello.exe`, macOS·Linux에서는 `./hello`로 실행합니다. IDE에서는 빌드·실행 버튼을 사용할 수 있습니다. 소스를 수정하면 다시 빌드해야 새 내용이 실행됩니다.

| 코드 | 지금 이해할 의미 |
| --- | --- |
| `#include <iostream>` | 입력·출력에 필요한 선언을 가져옴 |
| `using namespace std;` | 이 예제에서 `std::cout`을 `cout`으로 쓸 수 있게 함 |
| `int main()` | 일반적인 C++ 프로그램에서 실행이 시작되는 함수 |
| `{`와 `}` | 실행할 코드의 묶음인 블록 |
| `cout << "Hello World"` | 오른쪽 내용을 화면으로 보냄 |
| `'\n'` | 줄바꿈 문자 |
| `;` | 문장의 끝을 표시 |
| `return 0;` | `main`을 끝내고 정상 종료를 알림 |

`std`는 표준 라이브러리 이름이 들어 있는 네임스페이스입니다. 지금은 `using namespace std;`를 사용해 예제를 읽고, 직접 이름을 나누는 방법은 2주차에서 배웁니다.

**직접 바꾸기:** `Hello World`를 자기 이름으로 바꾸세요. 큰따옴표는 유지합니다. 다음으로 출력문을 하나 더 넣어 두 줄을 출력하세요.

### 오류 메시지는 어디부터 읽나요?

```text
.cpp 작성 → 전처리·컴파일 → 링크 → 실행 파일 → 실행
```

- **컴파일 오류:** 세미콜론 누락, 잘못된 이름 등으로 번역에 실패합니다. 첫 오류의 파일명과 줄 번호부터 확인하세요.
- **링크 오류:** 번역한 코드들을 연결하지 못합니다. `main`이 없거나 필요한 함수의 구현이 빠진 경우가 있습니다.
- **실행 결과 오류:** 실행은 되지만 답이 다릅니다. 입력과 변수 값을 한 줄씩 추적하세요.

## 2. 변수는 값을 다시 사용하기 위한 이름

숫자를 여러 번 직접 쓰면 수정하기 어렵습니다. 값에 이름을 붙이면 의미도 드러납니다.

```cpp
int score = 80;
score = 95;
cout << score << '\n';
```

이처럼 `main`이 없는 짧은 코드는 앞 예제의 `main` 안에서 실행하는 **코드 조각**입니다.

| 부분 | 의미 |
| --- | --- |
| `int` | 정수를 저장하는 자료형 |
| `score` | 변수 이름 |
| `80` | 코드에 직접 적은 값, 즉 리터럴 |
| `int score = 80;` | 변수를 만들며 첫 값을 넣는 초기화 |
| `score = 95;` | 이미 있는 변수에 새 값을 넣는 대입 |

두 줄을 실행하면 `score`에는 마지막에 저장한 `95`가 남습니다. `80`과 `95`가 동시에 들어 있지는 않습니다.

```cpp
int score = 80;
score = score + 5;
```

`=`는 수학의 등호와 다릅니다. **오른쪽의 현재 값으로 계산한 뒤 왼쪽에 저장**합니다. 따라서 `80 + 5`를 계산해 `score`를 `85`로 바꿉니다. `score += 5;`도 같은 효과입니다.

> [!CAUTION]
> 함수 안에서 `int score;`라고만 쓰면 읽을 수 있는 값이 준비된 것이 아닙니다. `int score = 0;`처럼 초기화하거나, 입력이 성공한 뒤 읽어야 합니다. 초기화되지 않은 값을 실행해서 결과를 확인하는 연습은 하지 않습니다.

### 어떤 자료형을 고를까요?

| 저장할 값 | 자료형 | 초기화 예 |
| --- | --- | --- |
| 개수·점수 같은 정수 | `int` | `int count = 3;` |
| 큰 정수 | `long long` | `long long population = 8000000000LL;` |
| 소수 부분이 필요한 수 | `double` | `double average = 82.5;` |
| 참·거짓 | `bool` | `bool passed = true;` |
| 영문자 하나 | `char` | `char grade = 'A';` |
| 이름·문장 | `string` | `string name = "Alex";` |

`string`을 쓰려면 `<string>`도 포함합니다. `string`은 기본 자료형이 아니라 표준 라이브러리의 자료형입니다.

`'7'`은 문자이고 `7`은 계산에 쓰는 정수입니다. `'A'`는 작은따옴표로 묶은 문자, `"A"`는 큰따옴표로 묶은 문자열입니다. `char grade = "A";`는 자료형이 맞지 않습니다.

변수 이름은 `studentScore`처럼 의미를 드러내세요. 이 수업에서는 영문자·숫자·밑줄을 사용하되 숫자로 시작하지 않고, 공백과 `int`, `return` 같은 예약어는 쓰지 않습니다. 대소문자는 구별합니다.

## 3. 입력 → 계산 → 출력 연결하기

종이에 가격과 수량을 적어 계산하듯, 프로그램도 값을 받아 계산한 뒤 결과를 보여 줍니다.

```cpp
#include <iostream>
using namespace std;

int main() {
    int price = 0;
    int quantity = 0;

    if (!(cin >> price >> quantity) || price < 0 || price > 10000
        || quantity < 0 || quantity > 100) {
        return 1;
    }

    const int total = price * quantity;
    cout << total << '\n';
    return 0;
}
```

이 예제는 가격 `0~10000`, 수량 `0~100`인 정수 입력으로 연습합니다. `if` 블록은 입력 실패나 범위 밖 값이면 계산하지 않고 종료하는 부분입니다. 조건문의 문법은 1주차에서 다루고, 지금은 입력·계산·출력 세 줄을 따라가세요.

입력:

```text
1500 4
```

출력:

```text
6000
```

| 실행 위치 | `price` | `quantity` | `total` |
| --- | --- | --- | --- |
| 초기화 후 | 0 | 0 | 아직 만들지 않음 |
| 입력 성공 후 | 1500 | 4 | 아직 만들지 않음 |
| 곱셈 후 | 1500 | 4 | 6000 |

`cin >> price >> quantity`는 공백이나 줄바꿈으로 구분한 값을 순서대로 넣습니다. `cout <<`는 출력, `cin >>`는 입력입니다. 입력을 기다리는 동안 화면이 멈춘 것처럼 보여도 값을 입력하고 Enter를 누르면 계속됩니다.

`const`는 초기화한 뒤 이 이름으로 값을 바꾸지 않겠다는 뜻입니다. 계산이 끝난 `total`을 실수로 수정하는 일을 막습니다.

## 4. 나눗셈에서 가장 많이 하는 실수

**실행 전에 예상해 보세요:** 다음 세 변수에는 각각 어떤 값이 저장될까요?

```cpp
int quotient = 7 / 2;
int remainder = 7 % 2;
double average = 7 / 2;
```

| 식 | 결과 | 이유 |
| --- | --- | --- |
| `7 / 2` | `3` | 정수끼리 나누면 소수 부분을 버림 |
| `7 % 2` | `1` | 두 개씩 세 묶음을 만들고 하나가 남음 |
| `double average = 7 / 2` | `3.0` 저장 | 계산을 끝낸 정수 3을 `double`에 저장 |
| `7.0 / 2` | `3.5` | 피연산자 하나가 실수이므로 실수 나눗셈 |

`7 = 2 * 3 + 1`에서 `/`는 몫 3, `%`는 나머지 1을 얻습니다. 음수의 정수 나눗셈도 소수 부분을 **0 방향으로** 버립니다. 짝수는 `number % 2 == 0`, 홀수는 음수까지 고려하면 `number % 2 != 0`으로 검사합니다.

> [!CAUTION]
> 정수의 `/`와 `%`에서 나누는 수가 0이면 정상 결과가 정의되지 않습니다. 0으로 나누는 예제를 직접 실행하지 마세요.

### 계산의 묶임을 읽기

곱셈·나눗셈·나머지는 덧셈·뺄셈보다 먼저 묶입니다. 같은 우선순위의 산술 연산자는 왼쪽부터 묶입니다.

```text
2 + 3 * 4 = 2 + 12 = 14
(2 + 3) * 4 = 5 * 4 = 20
10 - 3 - 2 = (10 - 3) - 2 = 5
```

이것은 **식이 어떻게 묶이는지**에 대한 규칙입니다. 모든 피연산자의 실행 순서까지 정해 주는 것은 아닙니다. 복잡한 식은 괄호나 여러 문장으로 나누세요.

## 5. 계산 결과를 조건으로 표현하기

`=`가 저장이라면 `==`는 같은지 묻는 비교입니다. 비교 결과는 `bool`의 두 값 `true`, `false` 중 하나입니다.

| 비교 | 의미 | 예 |
| --- | --- | --- |
| `==`, `!=` | 같다, 다르다 | `score == 100` |
| `<`, `<=` | 작다, 작거나 같다 | `score <= 100` |
| `>`, `>=` | 크다, 크거나 같다 | `score >= 60` |

```cpp
int score = 85;
bool passed = score >= 60;
cout << boolalpha << passed << '\n';
```

출력은 `true`입니다. `boolalpha` 없이 출력하면 `true`는 `1`, `false`는 `0`으로 보입니다.

조건이 여러 개면 논리 연산자로 연결합니다.

| 연산자 | 말로 읽기 | 참이 되는 조건 |
| --- | --- | --- |
| `&&` | 그리고 | 두 조건이 모두 참 |
| `\|\|` | 또는 | 하나 이상 참 |
| `!` | 반대 | 원래 조건이 거짓 |

```cpp
int age = 20;
bool hasTicket = true;
bool canEnter = (age >= 18) && hasTicket;
```

나이가 20이므로 첫 조건은 참이고, 티켓도 있으므로 `canEnter`는 참입니다. `hasTicket`만 `false`로 바꾸면 전체가 거짓이 됩니다. 이 결과로 실행할 코드를 고르는 방법이 다음 강의의 `if`입니다.

## 6. 함께 풀기: 전체 주문에 할인 한 번 적용하기

앞의 가격 계산 프로그램에 `discount`를 추가하세요. 가격 `1500`, 수량 `4`, 전체 할인액 `1000`을 입력받으면 `5000`을 출력해야 합니다. 할인액은 0 이상 전체 금액 이하입니다.

1. 세 입력을 저장할 변수를 정합니다.
2. ‘전체 가격에서 할인을 한 번 뺀다’를 식으로 적습니다.
3. 계산 후 출력할 변수가 무엇인지 말합니다.
4. 할인액 0과 전체 금액만큼 할인하는 경우도 예상합니다.

> [!QUIZ]
> `(price - discount) * quantity`로 계산해도 될까요?

> [!ANSWER]
> 안 됩니다. 그 식은 상품마다 할인합니다. `price * quantity - discount`여야 주문 전체에서 한 번만 할인합니다. 예시에서는 `6000 - 1000 = 5000`입니다.

## 7. 수업을 마치기 전 확인

> [!QUIZ]
> `int x = 5;` 다음에 `x = x + 1;`을 실행하면 `x`는 무엇인가요? `x == 6`은 무엇을 하나요?

> [!ANSWER]

> [!QUIZ]
> `double result = 5 / 2;`에서 왜 2.5가 저장되지 않나요? 어떻게 고치나요?

> [!ANSWER]
> 오른쪽이 먼저 정수 나눗셈으로 2가 됩니다. `5.0 / 2`처럼 계산 전에 피연산자 하나를 실수로 만들면 2.5가 됩니다.

**발표자 마무리:** 참가자가 ‘값 받기 → 계산하기 → 결과 보여 주기’를 자기 코드에서 짚을 수 있으면 다음 강의로 넘어갑니다. 문법 오류가 남으면 첫 오류부터 함께 고칩니다.

## 보충: 자료형의 범위와 다른 표기

### 큰 정수와 오버플로

자료형은 표현할 수 있는 범위가 있습니다. 보통의 32비트 `int`는 약 -21억부터 21억까지 표현합니다. 정확한 범위는 `<limits>`의 `numeric_limits<int>::min()`과 `max()`로 확인합니다.

부호 있는 정수의 범위를 넘기는 계산은 **정의되지 않은 동작**입니다. 최댓값 다음에 항상 최솟값이 된다고 가정하면 안 됩니다.

```cpp
long long total = 100000LL * 100000;
```

`LL`은 첫 피연산자를 `long long`으로 만듭니다. **계산 전에** 넓은 자료형을 사용해야 합니다. 왼쪽 변수만 `long long`으로 바꾸어도 오른쪽의 `int * int`가 안전해지는 것은 아닙니다.

### 지금은 표를 찾아보면 되는 내용

| 항목 | 알아둘 점 |
| --- | --- |
| `float` | 실수형이며 `3.14f`처럼 `f`를 붙임. 일반 실수 계산은 `double` 사용 |
| `0x2A` | 16진수로 쓴 정수 42 |
| `<cstdint>` | 제공되는 환경에서 `std::int32_t`, `std::int64_t`처럼 정확한 비트 폭 사용 |
| signed / unsigned | 음수 가능 여부가 다름. unsigned는 범위를 넘으면 순환하므로 무조건 더 안전한 정수형이 아님 |
| `std::endl` | 줄바꿈과 출력 버퍼 비우기를 함께 수행. 단순 줄바꿈은 `'\n'` 사용 |
| `int score{80};` | 중괄호 초기화. `int score{3.14};` 같은 축소 변환을 막음 |

### 논리 연산자의 단축 평가

```cpp
int divisor = 0;
bool largeQuotient = (divisor != 0) && (10 / divisor > 2);
```

`&&`는 왼쪽이 거짓이면 오른쪽을 평가하지 않습니다. 위에서는 나눗셈을 실행하지 않아 `largeQuotient`가 거짓입니다. `||`는 왼쪽이 참이면 오른쪽을 평가하지 않습니다. 안전한 조건을 왼쪽에 두는 이유입니다.
