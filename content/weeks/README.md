# 강의노트 파일 안내

- 이 폴더에 `week-00.md`, `week-01.md` 형식의 Markdown 파일을 넣습니다.
- 0주차부터 사용할 수 있으며 주차 숫자순으로 자동 정렬됩니다.
- 화면에 표시할 강의 제목은 `titles.json`에서 별도로 설정합니다.
- Markdown 안의 `#`, `##`, `###` 제목은 본문과 오른쪽 목차에 표시됩니다.
- `week-4.md`와 `week-04.md`처럼 같은 주차 파일을 동시에 두면 중복 오류가 발생합니다.
- 이 README와 `week-숫자.md` 형식이 아닌 파일은 강의 목록에서 제외됩니다.
- 초안은 이 폴더 밖에 보관합니다.

로컬 개발 서버는 파일 변경을 감지합니다. Vercel 사이트에는 GitHub push 후 새 배포가 완료되어야 변경 내용이 반영됩니다.
